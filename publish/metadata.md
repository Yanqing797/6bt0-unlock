## 功能

- 🎟️ **一键永久会员**：利用站点支付回调不校验签名的问题，0 元开通终身会员
- 📥 **导出全部网盘直链**：阿里 / 夸克 / 迅雷 / 百度 / 115 / 光鸭 / UC / 123 / 移动，带提取码
- 🧾 **批量导出**：一次填多个影片 id，串行抓完打包下载
- 👶 **自动注册小号**：没账号时点一下自动注册并登录

## 用法

1. 打开 6bt0 或 0bt0~9bt0 任意镜像
2. 右下角面板：先「自动注册小号」（填一道算术验证码），再点「一键解锁永久会员」
3. 影片页点「导出本页直链」，直链进剪贴板并自动下载 txt

## 原理

站点的支付回调 `/notify` 不校验第三方支付网关签名，任意请求带
`out_trade_no` + `trade_status=TRADE_SUCCESS` 即可把订单标记为已支付，
服务端随后按订单的 `vip_id` 写入会员时长。
