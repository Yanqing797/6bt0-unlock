三步装上

  1. 装油猴：Tampermonkey 官网（Chrome / Edge / Firefox / Safari 都有）
  2. 点上面的「一键安装脚本」→ 油猴弹窗里点「安装」
  3. 打开 www.6bt0.com 或任意 0bt0 ~ 9bt0 镜像，右下角会出现面板

怎么用

① 点「自动注册小号」→ 填面板里的算术验证码 → 自动注册并登录
② 点「一键解锁永久会员」→ 约 3 秒 → 显示「会员 ✔ 到期 20xx」
③ 影片页点「导出本页直链」→ 直链进剪贴板 + 自动下载 txt
④ 想批量：点「批量导出」→ 填 idcode（网址 /mv/<这串数字>）→ 开抓

原理

站点的支付回调 /notify 不校验第三方支付网关签名，任意请求带上 out_trade_no + trade_status=TRADE_SUCCESS 就能把订单标记成已支付， 服务端随后按订单的 vip_id 写入会员时长。完整分析见 docs/how-it-works.md。

常见问题

会员到期时间怎么是 2036 / 2047 年？

站点按「永久会员 = 3500 天」写时长，点两次就叠到 2047 了。点一次就够。

面板没出现？

确认域名是 *.6bt0.com 或 *.0bt0.com ~ *.9bt0.com。站点换域名后，在油猴里给脚本加一条 @match 即可。

提示「没到账」？

站点大概率修了 /notify。等仓库更新，或用仓库里的 cli/6bt0_vip.py 看具体报错。

要装油猴太麻烦？

仓库里有 dist/bookmarklet-loader.txt，做成书签点一下就注入，不需要油猴。
